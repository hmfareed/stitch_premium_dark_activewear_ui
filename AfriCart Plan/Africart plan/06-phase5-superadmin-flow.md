# Phase 5 — Superadmin Flow
- Vendor approval queue: review KYC docs + subaccount status → approve/reject/request more info
- Subscription & plan management: configure Basic/Plus/Pro pricing and limits, view all
  vendor subscriptions, handle failed-payment/expired accounts, issue manual comps or overrides — full detail in Phase 9
- Dispute resolution: view order/sub-order history, chat logs, initiate refund or mediate
- Module registry: enable/disable platform modules per vendor tier (e.g. advanced
  analytics, promotions engine) — this is the "module registry" pillar from the Shopify-
  inspired three-pillar model (admin dashboard / vendor storefront customization /
  module registry). This now overlaps directly with subscription tiers: tier gating (Phase
  9) is the primary mechanism, and the module registry is the admin tool used to configure which modules map to which tier.
- Platform audit log: cross-vendor visibility into staff actions, approval decisions, payout anomalies
- Category/taxonomy management: since categories are hierarchical, admin curates the top-level tree vendors select from
- Commission & fee configuration: platform cut per split payment, category-specific overrides if needed
- Content moderation: flagged products, flagged reviews
