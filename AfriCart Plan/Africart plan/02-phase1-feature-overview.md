# Phase 1 — Feature Overview

| Domain | Features |
|---|---|
| Discovery | Search, category browse, vendor store pages, featured/trending, recently viewed |
| Cart & Checkout | Multi-vendor cart, cart-splitting, Mobile Money + card checkout, GhanaPost GPS address capture |
| Vendor Ops | Store setup wizard, product CRUD, inventory, order management, staff invites, storefront customization |
| Monetization | Vendor verification, subscription tiers (Unverified/Basic/Plus/Pro), plan-based feature gating, annual billing |
| Fulfillment | Rider assignment, delivery tracking, proof-of-delivery |
| Trust & Safety | Vendor KYC/approval gate, dispute handling, review/rating system |
| Admin | Vendor approval queue, payout oversight, module registry, platform-wide audit log |
| Comms | SMS (order status, OTP, staff invites), in-app notifications |
